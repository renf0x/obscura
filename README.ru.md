## Вводная

Obscura — открытый проект домашнего видеонаблюдения. Цель — удобная система, которая целиком принадлежит
вам и заменяет сервисы производителей камер (или их аналоги), где хранение записей в облаке и часть функций
доступны только по платной подписке.

Всё работает на вашем сервере. Камеры не выходят в интернет, с ними общается только хаб. Когда в зоне
появляется движение или человек, хаб записывает короткий ролик, присылает уведомление на телефон и сохраняет
запись туда, куда вы скажете: на сам хаб, в S3, на WebDAV или в любое облако, с которым работает rclone.

## Снаряжение

- **Видео в реальном времени** из любого места. Телефон подключается к хабу, а не к камере.
- **Зоны на кадре.** Вы обводите нужные участки и для каждого выбираете, на что реагировать: на движение,
  на людей или на то и другое. Людей распознаёт нейросеть YOLOX-nano прямо на хабе.
- **Короткие ролики вместо круглосуточной записи**: 4 секунды до события и до 40 секунд после.
- **Хранилище выбираете вы.** Ролики остаются на хабе, копии можно отправлять в S3, на WebDAV
  (Яндекс Диск, Nextcloud) или в любое хранилище [rclone](https://rclone.org): Google Drive, Dropbox,
  OneDrive, в том числе с шифрованием.
- **Разные звуки уведомлений**: громкая трель, если в кадре человек, мягкий сигнал, если просто движение.
  На Android уведомления идут через [UnifiedPush](https://unifiedpush.org), без сервисов Google, и
  шифруются на всём пути от хаба до телефона.
- **Разговор и сирена** — если у камеры есть динамик. Зажимаете кнопку, говорите, фраза звучит из камеры.
  Сирену можно включить вручную или настроить на срабатывание, когда в кадре человек. Подробнее о том, какие
  камеры это поддерживают, в разделе [Камеры](#камеры).
- **Инструкции в приложении** на русском и английском: сервер, камеры, удалённый доступ, облако, уведомления.

## Как устроено

```text
 Камера ──RTSP──▶ Хаб (ваш сервер) ──HTTPS / Tailscale──▶ Телефон
                   │  go2rtc: одно подключение к каждой камере
                   │  движение + люди (YOLOX-nano) в зонах
                   │  кольцевой буфер ffmpeg → ролики
                   └─ rclone ──▶ S3 / WebDAV / Google Drive …
```

| Часть | Стек |
|-------|------|
| `hub/` | Python 3.12, FastAPI, OpenCV, onnxruntime (YOLOX-nano), ffmpeg, rclone, SQLite |
| `deploy/` | Docker Compose (хаб + [go2rtc](https://github.com/AlexxIT/go2rtc)) или скрипт установки на systemd |
| `app/` | Flutter (Android, iOS), плеер media_kit |

## Развёртывание

Есть два варианта установки. В обоих в конце вы получаете код сопряжения и вводите его в приложении, по
одному коду на каждый телефон.

### Вариант А: домашний компьютер с Docker

Подойдёт любой 64-битный компьютер на Linux. Raspberry Pi 4 (2 ГБ) справится с одной-двумя камерами,
мини-ПК на Intel N100 — с десятью.

```sh
curl -fsSL https://get.docker.com | sh        # если Docker ещё не установлен
git clone https://github.com/renf0x/obscura
cd obscura/deploy
mkdir -p data && sudo chown -R 1000:1000 data
docker compose up -d --build
docker compose logs hub | grep -i pairing      # одноразовый код сопряжения
```

До запуска укажите свой часовой пояс в `deploy/docker-compose.yml` (параметр `TZ`), иначе расписания и
даты роликов будут сдвинуты. Код для ещё одного телефона: `docker compose exec hub python -m obscura pair`.

### Вариант Б: сервер на Debian или Ubuntu, без Docker

Подходит для VPS или домашнего сервера, к которому нужен доступ по HTTPS.

```sh
git clone https://github.com/renf0x/obscura
cd obscura/deploy
sudo ./install.sh                  # или со своим доменом: sudo ./install.sh cam.example.com
```

Скрипт устанавливает хаб и go2rtc как службы systemd. Снаружи они недоступны, запросы к ним принимает
Caddy и сам получает HTTPS-сертификат. Если домена нет, скрипт возьмёт адрес вида `<ваш-ip>.sslip.io`.
В ufw он открывает только порты 80 и 443, остальные правила файрвола, VPN и SSH не трогает.

В конце скрипт покажет QR-код. Откройте приложение, нажмите **Сканировать QR-код**, и телефон подключится.
Для следующего телефона запустите `obscura-pair`.

Хаб должен видеть камеры: они в той же сети, что и сервер, или сервер подключён к домашней сети через
туннель. Если запустить скрипт повторно, он обновит хаб, а данные в `/opt/obscura/data` сохранятся.

### Телефон

APK лежит в [Releases](https://github.com/renf0x/obscura/releases), можно собрать и самому:
`cd app && flutter build apk --release`. При первом запуске введите адрес хаба и код (в варианте А адрес
выглядит как `IP_ХАБА:7878`) или отсканируйте QR-код из варианта Б.

### Камеры

Obscura тестировалась с камерами TP-Link Tapo, поэтому для них ниже пошаговая инструкция. Остальные камеры
подключаются по тому же принципу, но конкретные модели мы не проверяли.

**TP-Link Tapo**

1. Подключите камеру к Wi-Fi в приложении Tapo и обновите прошивку.
2. В приложении Tapo откройте камеру → Настройки → «Расширенные настройки» → «Учётная запись камеры» и
   задайте логин и пароль (6–32 символа). Это не ваш TP-Link ID, а отдельный локальный логин для видеопотока.
3. Если в настройках есть пункт «Совместимость со сторонними сервисами» (иногда он в Tapo Lab), включите
   его. На новых прошивках без него RTSP может не работать.
4. Узнайте IP камеры: Настройки → «Информация об устройстве». Лучше закрепить этот адрес за камерой в
   роутере, чтобы он не менялся.
5. В Obscura: «Камеры» → «Добавить камеру» → TP-Link Tapo, затем IP, логин и пароль из шага 2. Кнопка
   «Найти камеры в сети» находит камеру сама, если хаб с ней в одной сети.
6. Для разговора и сирены введите в настройках подключения камеры пароль от аккаунта TP-Link, с которым
   вы входите в приложение Tapo. Хаб хранит не сам пароль, а только его хэш. Сирена на Tapo включает
   встроенную тревогу камеры: звук и свет.

**Другие камеры**

Подойдёт любая камера, которая отдаёт видео по RTSP или ONVIF. Для Hikvision, Dahua/Imou и Reolink
приложение подставит пути к потокам само. Для остальных путь есть в инструкции производителя или в базе
[ispyconnect.com/cameras](https://www.ispyconnect.com/cameras). У некоторых производителей RTSP по
умолчанию выключен или требует отдельный логин, как у Tapo, поэтому загляните в настройки камеры.
Облачные камеры без RTSP (часть Xiaomi, Ring, Arlo) подключить нельзя.

Разговор и сирена работают, если у камеры есть динамик и она поддерживает двусторонний звук по RTSP/ONVIF
(Profile T) с кодеком G.711A. Это умеет большинство моделей Hikvision, Dahua и Reolink с динамиком. Тогда
включите «У камеры есть динамик» в настройках подключения, а сирена будет громким сигналом через динамик.

### Доступ вне дома

В варианте А установите [Tailscale](https://tailscale.com) на хаб и на телефон и подключайтесь к адресу
хаба в Tailscale. Порты на роутере открывать не нужно. В варианте Б хаб уже доступен по HTTPS.

Подробно каждый шаг расписан в приложении: *Настройки → Инструкции*.

## Разработка

```sh
# хаб
cd hub && python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt && pytest

# приложение
cd app && flutter pub get && flutter analyze && flutter test
flutter run
```

Для работы с настоящими камерами нужны `ffmpeg` в PATH и запущенный go2rtc. Тестам хватает заглушек.

## Безопасность

Нашли уязвимость — сообщите через GitHub: вкладка **Security** → **Report a vulnerability**. Такой отчёт
видит только автор, поэтому проблему можно исправить до того, как о ней узнают все. Как Obscura защищает
доступ, пароли и записи, описано в [SECURITY.md](SECURITY.md).
